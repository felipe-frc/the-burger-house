# Owner The Burger House

Painel administrativo React e TypeScript. As operações passam pela API ASP.NET Core, com sessão Owner e proteção CSRF.

Use o [guia do portfólio local](../docs/postgresql-portfolio.md) para acessar o Owner com PostgreSQL e dados sintéticos. Para editar componentes em Vite, configure a origem local da API no processo e execute `npm run dev` neste diretório. A base do painel é `/admin/`.

- `npm run lint` verifica TypeScript.
- `npm test` executa os testes dos serviços.
- `npm run build` gera os assets.
