# Frontend oficial

Esta é a aplicação React oficial da The Burger House 2.0. Consulte o README da raiz para instalação, comandos, API local e publicação. Os contratos de catálogo e checkout são importados de `../shared/storefront`.

Execute `npm run dev`, `npm run lint`, `npm test` e `npm run build` neste diretório ou use os comandos encaminhados da raiz. Preserve `.env.local` e use o backend isolado em localhost:5041 para homologação.
